# Continuous interview session — approved redesign

The user approved replacing individual LLD, DSA and behavioral screens because an interview may mix all three. This supersedes topic and stage selection in the original workspace specification.

Use one conversation with all relevant response guidance available to the model on every turn. Infer intent from the question and context, combine guidance for mixed questions, and ask a targeted clarification when ambiguous. Do not impose a separate classifier or manual stage selection.

Preserve current code and pending proposals across non-code follow-ups. Show code when there is a proposal or working code, and allow users to pin it open. Retain explicit review, stale-version rejection and undo. Pin editable session requirements separately from bounded conversation history. Preserve legacy saved sessions without requiring a topic choice.

Verification covers mode-free request validation, combined instructions, bounded context and interrupted turns, legacy sessions, cross-topic request payloads and code preservation, existing code review workflows, type checking and production build. Real model quality and Windows audio remain live acceptance items.
